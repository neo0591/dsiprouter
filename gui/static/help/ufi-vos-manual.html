3推荐配置顺序

  1. 运营商组 — 添加客户 VOS（type=8，gwid≥100，填公网 SIP IP）。保存后 重载 Kamailio。
  2. 通信管理 → UFI 通信配置 — 确认设备已纳管；划入号码池；设置策略；绑定「任意被叫 ← 对接 VOS」。
  3. 客户 VOS — 路由网关「dsip接入」前缀改为 0,1,400,800,9（勿逐号）；网关组不能为空。
  4. 端到端链路 #topo — 核对注册数、IP 认证、任意被叫绑定、路由一致性为绿。
  5. 拨测 — 坐席拨未单独配置过的手机号；CDR 被叫经由=dsip接入且非 500。
  6. （可选）短信中心 — 同池设备作通道，配置模板/频控后单发验收。

4页面 A：运营商组 /carriergroups

侧栏 运营商组。把客户 VOS3000 登记为 dSIP 可信任的运营商网关，供 UFI 落地与外呼进线识别。

图 2 · 现网截图：搜索「VOS」可见 VOS3000 Carrier Group（ID 100，运营商 100,141）。列表中的编号即通信管理「任意被叫」里的 gwid。

4.1 新增一台 VOS

  1. 打开 运营商组，点 添加。
  2. 填写组名（如 VOS3000 Carrier）。
  3. 在组内添加终端：主机/IP = VOS 公网 SIP 地址；认证方式选 IP 认证（不要 SIP 摘要，除非客户要求）。
  4. 保存后到右上角执行 重载 → 重载 Kamailio。
  5. 到通信管理确认该 gwid 出现在「任意被叫 ← 对接 VOS」列表中。
注意：系统样例网关 gwid 1–55 不要当生产 VOS 用。生产 VOS 使用 type=8 且 gwid≥100（如 100、101）。IP 变更后务必同步改 address 放行（port=0 表示任意源端口）。

4.2 多 VOS

每套 VOS 建一个运营商组/网关。通信管理里：P1 勾选 VOS#100，P2 勾选 VOS#101；各池 UFI 设备的 carrier 选同一 gwid。

5.1 号码池与设备

图 3 · 现网截图：UFI 通信配置 — 上方为选路现状（路由同步一致），下方为号码池列表。选中一行后可改策略，并点「编辑触发号 / 任意被叫」。
  1. 新建号码池（可选）：池 ID 如 P2，选策略（轮询 / 主备 / 负载）。
  2. 设备入池：在下方设备台账勾选 UFI，划入目标池，确认 enabled + in_pool，carrier = 对应 VOS gwid。
  3. 打开 编辑触发号 / 任意被叫：
    • 外呼触发号：精确 Request-URI 命中才进池（逗号分隔；保存=整表覆盖；留空=清空）。
    • 任意被叫 ← 对接 VOS：勾选本池服务的 VOS gwid。该 VOS 通配打来的任意长号进本池。
    • 全局兜底：仅当源 IP 认不出 VOS 时使用，一般不勾。
生产任意号码：不必给每个被叫加触发号。VOS 前缀通配 + 本池勾选对应 VOS「任意被叫」即可。触发号只用于「打固定号码进指定池」的场景。

5.2 号码与路由 Tab

  • 外呼指定线路 / 呼入 SIM：维护 dbaliases（别名 → IMEI）。
  • 使用「生成客户指引单」让客户改 VOS 话机 DIDs、网关前缀。
  • 可执行 同步路由：校准 dr_rules / subscriber 与号码池一致。

5.3 开户向导（通信配置内）

可用「新增通信配置向导」：选 IMEI、SIM、池、carrier → 一键入池并同步路由。设备也可在 UFI 设备 模块上电自动纳管后再来划池。

6页面 C：端到端链路 /ufi-callcenter#topo

通信管理打开后默认即本页。数据来自实时接口 /api/v1/ufi/comm/topo，与运营商组、号码池、设备注册联动（约 10 秒刷新）。

图 4b · 现网截图：端到端链路 — 各节点显示真实主机、池选路（如 P1←VOS100）、IP 认证与路由一致性

如何读状态

节点正常表现异常时
UFI 设备池在线≈注册≈池内可用注册为 0 → 查 subscriber / 网络
dSIPRouter路由一致性绿；触发号与配置一致提示缺 subscriber/规则 → 点同步路由

7页面 D：短信中心 /ufi-sms

侧栏进入短信中心。UFI 号码池同时作为短信通道：平台下发 SIP MESSAGE（R-URI=IMEI，X-SMS=对端号码），由 UFI 经蜂窝送达。

图 5 · 现网截图：短信中心「发送短信」— 可用通道 2/2，支持单发/群发、模板、通道选择、黑名单与敏感词校验

7.1 单发验收

  1. 确认通信管理中至少 1 台 UFI：在线、已注册、在池、SIM 就绪。
  2. 打开 短信中心 → 发送短信。
  3. 填写对端号码与内容（营销类注意签名/退订；敏感词即时校验）。
  4. 发送后到 收发记录 看状态；失败常见原因：通道离线、黑名单、夜间静默、频控。

7.2 群发与治理

  • 群发任务：导入号码、选模板/池、设速率与时段。
  • 通道与频控：按池限制每小时条数，避免单卡被运营商限制。
  • 模板 / 黑名单 / 敏感词：合规与风控，发送前自动拦截。
短信与通话共用 UFI。高峰时请在通信管理观察并发，避免语音与短信抢满 max_concurrent。

8客户 VOS3000 配合清单

以下在 客户 VOS 管理界面操作。通信管理「变更任务」可生成正式指引单发给客户。

8.1 路由网关「dsip接入」（必做 · 任意外呼）

  1. 打开：网关管理 → 路由网关（不是对接网关同名项）→ 指向 dSIP 的项（如 dsip接入）。
  2. 网关组必须已勾选（为空会导致应用 NPE / 一直「应用中」）。
  3. 网关前缀改为通配：0,1,400,800,9（或 1,0,400,800）。不要填完整 11 位被叫白名单。
  4. 保存并应用；确认 mbx 侧 Prefix 已同步。

8.2 话机 DIDs（呼入）

话机管理 → 分机（如 1002）→ DIDs 追加 SIM/IMEI（保留原有号码，逗号分隔）。

8.3 对接认证

对接/落地到 dSIP 使用 IP 认证；dSIP 侧 address 对该 VOS IP 放行且 port=0。

  • 网关前缀已是通配，不是逐号列表
  • 网关组非空，应用成功
  • 坐席示闲、话机已注册
  • 从坐席拨未单独配置的手机号，CDR 被叫经由=dsip接入

10故障速查

现象多半原因处理
VOS CDR「无可用路由」前缀仍是逐号客户改通配前缀并应用
Server Internal Error(500)未绑任意被叫 / 无默认池通信配置勾选对应 VOS；确认 UFI 在线在池
应用一直转圈 / NPE路由网关「网关组」为空客户补网关组后重应用
触发号删不掉旧版种子回写（已修）强刷后保存应整表覆盖；仍异常联系我方
UFI 全不注册subscriber / 密码 / 网络重跑开户或同步路由；查 #topo 注册数
来显变成 IMEIX-VOLTE 未带上查桥接日志；确认走 UFI 池而非裸 drouting
短信失败通道离线 / 敏感词 / 频控短信中心记录原因；检查池内设备
#topo 数据不像现网浏览器缓存Ctrl+F5；看图例是否含 /ufi/comm/topo
